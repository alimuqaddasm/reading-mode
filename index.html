Connect your GitHub key

This page holds no course material. It reads your lessons from your private repos hub-data and hub-notes with a key that stays in this browser. The key never needs the hub itself. If you already connected the Work Map in this browser, the same key works here. Anyone else who opens this address sees only this page.

  1. On GitHub, open Settings, Developer settings, Personal access tokens, Fine-grained tokens, and generate a new token.
  2. Expiration: 90 days. Repository access: only select repositories, and pick hub-data and hub-notes.
  3. Repository permissions: Contents, read and write (write saves your notes and marks). Nothing else.
  4. Paste the token here.
