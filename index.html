Connect your GitHub key

This page holds no course material. It reads your lessons from your private hub repo with a key that stays in this browser. If you already connected the Work Map in this browser, the same key works here. Anyone else who opens this address sees only this page.

  1. On GitHub, open Settings, Developer settings, Personal access tokens, Fine-grained tokens, and generate a new token.
  2. Repository access: only select repositories, and pick hub.
  3. Repository permissions: Contents, read and write (write saves your notes and marks). Nothing else.
  4. Paste the token here.

The hub could not be read

Check your connection and that the key still has access to the hub repo, then try again.
